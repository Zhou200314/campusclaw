# 文件上传分析（简版）

**1. 上传逻辑**
教师登录后用 multipart/form-data 上传 → 校验会话与角色（未登录 401、学生 403）→ 限制单文件 10 MB（超限 413）→ 文件名净化、按班级落盘到 uploads/<班级>/<uuid>-文件名 → 提取正文 → 材料表与知识库表在同一事务内各写一行 → 返回 201。班级取自服务端会话，请求参数无法指定。

**2. 支持哪种文件类型**
上传不限制类型，任何文件都能上传与下载。能否进入知识库取决于正文提取：白名单（txt、md、csv、json、html、yaml 等 14 种）直接提取；扩展名不在白名单但内容是纯文本的，靠内容嗅探也提取；二进制格式不提取正文，只登记来源文件名。

**3. txt、md 以外的文件是否支持**
- 上传/下载：支持全部类型。
- 正文入库（可被搜索）：支持 csv、tsv、json、log、yml、yaml、html、htm、tex、srt、vtt 等文本类，以及任意扩展名的纯文本；不支持 docx、pdf、xlsx、图片、压缩包等二进制文档，它们能上传下载但搜不到内容。

**4. 不足**：正文只按 UTF-8 解码（GBK 会乱码）；扩展名优先于内容嗅探（二进制改名 .txt 会写入乱码）；无可执行文件黑名单、配额、去重与 docx/pdf 正文提取。
