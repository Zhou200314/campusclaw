# 文件下载权限与实现逻辑（简版）

下载需要权限。材料按班级隔离，下载是数据出口，因此下载与列表、详情共用同一套访问控制。

实现逻辑：请求进入 `GET /api/materials/:id/download` 后，先做会话鉴权，无 Cookie、令牌无效或已登出返回 401；再按会话中的班级查询 `SELECT * FROM materials WHERE id = ? AND class_id = ?`，班级不由请求参数指定；查不到记录（跨班或不存在）统一返回 404；最后确认附件存在，用 `res.download()` 以附件形式返回，响应头为 `Content-Disposition: attachment`，磁盘路径不出现在响应中。

实测结果：未登录 401；本班教师与学生均 200 且内容与上传一致；跨班、不存在 ID、非法 ID 均为同形 404；登出后用旧 Cookie 为 401。

设计要点：班级条件写进 SQL 而非事后判断；跨班与不存在返回同一文案，防止借此探测别班材料；学生可下载是角色边界的一部分，只有上传被禁止。

不足：种子材料只有文件名、磁盘上没有真实文件，下载会返回 404。
